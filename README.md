# AI-примерка одежды через IDM-VTON

Простой локальный проект для виртуальной примерки одежды с использованием модели [IDM-VTON](https://github.com/yisol/IDM-VTON) (ECCV 2024).

## Как это работает

1. Кладёте фото человека и фото одежды в папку `input/`
2. Запускаете `python run.py`
3. Получаете результат в `output/result.png`

Программа генерирует несколько вариантов и автоматически выбирает лучший.

## Требования к оборудованию

| Устройство | VRAM | Скорость | Качество |
|---|---|---|---|
| NVIDIA GPU (RTX 3090/4090, A6000) | ≥16 GB | ~30–60 сек | Лучшее |
| Apple Silicon (M1/M2/M3) | — | ~30–60 мин | Хорошее |
| CPU | — | Несколько часов | Хорошее |

**Рекомендуется:** NVIDIA GPU с ≥16 GB VRAM.

## Установка

### 1. Создайте виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# или: venv\Scripts\activate  # Windows
```

### 2. Запустите скрипт установки

```bash
chmod +x setup.sh
./setup.sh
```

Скрипт автоматически:
- Клонирует репозиторий IDM-VTON
- Установит все Python-зависимости
- Установит detectron2
- Скачает чекпоинты для препроцессинга (~700 МБ)

### 3. Первый запуск

При первом запуске `python run.py` будут автоматически скачаны модели с HuggingFace (**~15 ГБ**). Это одноразовая операция.

## Использование

```bash
# 1. Положите фотографии
cp /path/to/photo.jpg input/person.jpg
cp /path/to/tshirt.jpg input/cloth.jpg

# 2. Запустите генерацию
python run.py

# 3. Результат
open output/result.png
```

## Требования к фотографиям

### Фото человека (`input/person.jpg`)

- Один человек на фото
- Человек смотрит примерно в камеру
- Хорошо видна верхняя часть тела
- Руки не закрывают одежду
- Фото не размытое
- Нормальное освещение
- Без сильных поворотов тела
- Желательно фото по пояс или в полный рост

### Фото одежды (`input/cloth.jpg`)

- Одежда хорошо видна целиком
- Лучше всего — вид спереди
- Желательно белый или однотонный фон
- Без сильных складок
- Без рук, манекена или других предметов
- Одежда не должна быть обрезана по краям

### Поддерживаемые типы одежды

- Футболка
- Рубашка
- Худи
- Свитер
- Кофта
- Куртка

Брюки, обувь, шапки и аксессуары **не поддерживаются** в текущей версии.

## Устранение проблем

### Ошибка "не найден файл input/person.jpg"

Убедитесь, что файл лежит в папке `input/` с правильным именем.
Поддерживаются расширения: `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`.

### Ошибка "файл не является изображением"

Убедитесь, что файл — это настоящее изображение, а не текст или другой формат.

### Ошибка генерации

Попробуйте:
1. Использовать фото человека лучшего качества
2. Использовать фото одежды на белом фоне
3. Убедиться, что одежда — верхняя часть тела (футболка, рубашка и т.д.)
4. Убедиться, что на фото один человек

### Недостаточно памяти GPU (CUDA out of memory)

Если у GPU недостаточно VRAM:
- Попробуйте закрыть другие программы, использующие GPU
- В `run.py` можно уменьшить `INFERENCE_STEPS` до 30
- Или запускайте на CPU (будет медленно, но работать будет)

### detectron2 не устанавливается на macOS

```bash
CC=clang CXX=clang++ pip install 'git+https://github.com/facebookresearch/detectron2.git'
```
